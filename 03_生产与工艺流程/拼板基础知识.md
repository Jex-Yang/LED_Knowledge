# 拼板基础知识

在电子制造行业（如PCB生产、SMT贴片、插件焊接），拼板（Panelization）是将多个单一的小尺寸电路板（单板/PCS）通过特定方式组合成一张大板（拼板）的工程设计过程。对于数码管这类体积小、批量大的产品，拼板是提高生产效率、降低制造成本的关键环节。

本文件对拼板的目的、常见连接方式、尺寸规范及分板工艺进行系统梳理。

## 一、 为什么需要拼板？

1.  **提高生产效率**：贴片机（SMT）和波峰焊设备对过板尺寸有下限要求。如果板子太小，机器吸嘴频繁往返，效率极低。拼板能让机器一次性完成几十个单板的加工。
2.  **节省材料与成本**：PCB板厂在开料和电镀时，拼板能最大化利用覆铜板面积，减少边角料浪费。
3.  **保护机器轨道**：太小的板子无法在设备的传送轨道上平稳运行，容易卡板或掉板。
4.  **提升焊接良率**：大板在过回流焊或波峰焊时，受热更均匀，不易因单板过小而发生翘曲变形。

## 二、 常见的拼板连接方式

单板之间需要物理连接，且在加工完成后又要易于分离。行业主要有两种连接工艺：

### 1. V-Cut（V型切割 / V割）
*   **原理**：在相邻两块单板的边界处，用V型刀具在板子的正反面各切出一道一定深度的V型槽。残余厚度通常为原板厚的1/3（如1.6mm板厚，残余约0.5mm）。
*   **适用场景**：外形为规则的矩形或正方形单板，且分板线必须是**直线**。
*   **优缺点**：分板极其方便，用手一掰或用机器一滚就断，边缘平整无毛刺。缺点是必须贯穿整个拼板，无法做异形板，且V槽处不能走线，占用板面空间。

### 2. 邮票孔（Mouse Bite / 桥连）
*   **原理**：单板之间不完全断开，而是通过几个微小的连接点（像邮票边缘的锯齿）相连。连接点之间打一排小孔（孔径通常 0.5mm - 0.8mm）。
*   **适用场景**：异形板（如圆形、L型）、FPC软板，或者拼板内部需要留有空隙的情况。
*   **优缺点**：空间利用率极高，且因为有小孔缓冲，分板时的应力非常小，不会拉扯板上的元器件。缺点是分板后边缘会有粗糙的齿痕，可能需要人工打磨。

### 3. 工艺边（Edge Rail）
*   **原理**：如果单板边缘有高出板面的元件，或者板子周围没有足够的空间，通常会在拼板的最外围（上下或左右）增加一条宽 3mm - 5mm 的辅助边。
*   **作用**：提供机器轨道的夹持区、印锡膏的支撑区，以及贴片时的定位孔和光学MARK点。加工完成后，工艺边会被作为废料切除。

## 三、 拼板尺寸与数量规则

拼板的尺寸受限于贴片机、波峰焊、锡膏印刷机等设备的轨道宽度，行业内具有常规限制：

1.  **尺寸下限**：单板尺寸通常建议长宽均 ≥ 50mm。如果太小，拼板后整体尺寸也不能太小。
2.  **尺寸上限**：常规拼板最大尺寸通常控制在 **X轴 ≤ 400mm，Y轴 ≤ 350mm** 左右（极限视具体设备而定）。尺寸过大，过炉时板子中间容易受热塌陷（尤其是薄板）。
3.  **拼板数量**：
    *   通常建议采用**偶数**排列（如 2x2, 3x3, 4x6 等），便于对称分板，减少机器贴片的偏移，也方便包装清点。
    *   如果因为尺寸限制只能做奇数（如 1x5），建议在边缘加一条废料边凑成偶数，以保持平衡。
4.  **间距要求**：单板与单板之间必须留有分板间隙。V-Cut通常留 0（直接相连）；邮票孔连接通常留 1.6mm - 3.0mm，留出铣刀走线的空间。

## 四、 拼板上的定位与识别设计

1.  **MARK点（光学定位点）**：SMT贴片机识别坐标的基准。整个大拼板的**对角**必须放置至少2个MARK点。要求：直径 1.0mm 左右的实心圆，周边 2mm 范围内无阻焊油墨（露出裸铜或镀金），无其他走线。
2.  **定位孔（Tooling Hole）**：用于在加工设备上固定拼板。通常打在工艺边的对角，孔径一般为 1.5mm - 4.0mm，要求非金属化（不沉铜）。
3.  **基准符号**：在工艺边或废料区打上“十字”靶标，用于人工核对和模具冲压对位。

## 五、 分板（Depanelization）工艺

拼板完成所有焊接工序后，需要分离成单板。常见的分板方式：

1.  **手工分板**：依靠人工手掰或使用简易治具。成本最低，但应力极大，极易导致焊点撕裂或贴片电容开裂，不推荐用于精密数码管。
2.  **走刀式分板机（V-Cut分板）**：针对V-Cut拼板。上下两片圆刀沿着V槽划过，剪切应力小，边缘平整。
3.  **铣刀式分板机（Router分板）**：针对邮票孔拼板。机器控制铣刀沿着预设路径将连接筋切掉。精度极高，应力极小，适合异形板和高端产品。
4.  **冲压分板（模具冲切）**：在大批量生产中，使用重型冲床配合定制钢模一次性冲断。效率极高，但模具费贵，且对板子的平整度要求高。

## 六、 拼板设计的“坑”与失效排查

*   **板曲/翘曲**：拼板过大或铜箔分布极其不均匀，过回流焊后大板中间像“拱桥”一样隆起。导致贴片偏位或后续无法上机。
*   **应力拉扯**：手工掰板时，机械应力传递到了板内的芯片或焊点，导致原本完好的数码管出现“内部金线断裂”或“电阻微裂”。表现是测试时全部正常，但在客户端用几天后就不亮了。
*   **V槽偏移**：V-Cut切割线未对准，导致分板后单板尺寸超差，或切到了板内的走线。
*   **MARK点识别失败**：MARK点周围有丝印文字、或者MARK点与背景色对比度太低，导致贴片机频繁停机报错。
