# LED数码管行业基础知识库

欢迎来到**LED数码管（Seven-Segment Display）行业基础知识库**。

这个仓库致力于整理和分享LED显示制造行业的通用基础知识。无论你是刚入行的应届生、从其他行业（如IT、互联网）跨行过来的工程师，还是单纯的电子制造爱好者，这份文档都能帮你快速建立对数码管行业的系统认知。

本知识库**纯属开源科普**，不包含任何特定企业的商业机密、内部图纸或专有工艺数据。所有内容均基于行业通用标准（如GB/T、IEC等）及公开技术资料整理。

## 🛠️ 如何使用本知识库

1.  **按需查阅**：遇到不懂的物料、工艺或参数，直接查找对应的 `.md` 文件。
2.  **系统性学习**：建议按照 `基础原理 -> 核心材料 -> 生产流程 -> 测试标准` 的顺序阅读，构建完整的知识框架。
3.  **本地部署**：你可以直接 `git clone` 本仓库到本地，使用 Typora、Obsidian 或 VS Code 等 Markdown 编辑器打开阅读，体验更佳。
