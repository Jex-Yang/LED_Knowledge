# 数码管行业黑话词典

在电子制造和数码管（LED显示）行业，老一辈工程师、产线工人和销售们为了沟通高效（或者纯粹是因为懒得说全称），发明了大量的“行业黑话”。

对于刚入行的新人（尤其是跨行过来的）来说，听他们开会简直像在听天书。本词典收录了行业最常用的黑话，用通俗易懂的语言进行翻译，适合所有人查阅。

## 一、 物料与结构类（东西是什么）

*   **8字（八段）**：指数码管显示数字的区域，因为显示“8”需要用到所有笔画，所以业内常把“一位数字”直接叫“一个8字”。
*   **0.56 / 0.36**：指数码管的字高尺寸（英寸）。0.56英寸（约14.2mm）是微波炉、洗衣机上最通用的标准尺寸。
*   **REF / 塑壳 / 反射腔**：数码管最外面的那个塑料壳子。里面通常有反光的斜面，用来把芯片的光聚拢到面板上。
*   **灯芯 / Chip / SMD**：发光的最核心零件（发光二极管）。
*   **PIN / 引脚 / 针脚**：从数码管底部伸出来的金属插脚，用于插在客户的电路板上。
*   **面膜 / Film**：贴在塑壳正面的一层带图案的塑料薄膜。没点亮时是黑色的，点亮时能透出数字。
*   **菲林纸 / 菲林**：一种类似底片的透明材料。在开模或做面膜前，用来核对尺寸和图案的基准图纸。
*   **大板 / 小板**：为了生产效率，工厂会把很多小电路板拼成一张大板一起生产，大板就叫“拼板”，小块叫“单板/小板”。
*   **正装 / 倒装**：芯片的安装工艺。正装是要用极细的线把芯片连起来；倒装（DA）是把芯片翻过来直接贴在板子上，更先进、更亮、更耐造。
*   **金线 / 铜线**：连接芯片和电路板的极细金属线，比头发丝还细，非常容易断。

## 二、 生产与工艺类（东西怎么做）

*   **固晶**：把芯片用胶水粘死在电路板上的动作。
*   **压焊 / 打线**：用机器把金线焊在芯片和电路板上的动作。
*   **穿压PIN**：用机器把金属引脚硬挤进塑料壳里的动作。
*   **灌胶 / 点胶 / 封胶**：往塑料壳里注满环氧树脂或硅胶，用来防水防尘。
*   **过炉**：让电路板经过高温机器（回流焊或波峰焊）进行焊接的过程。
*   **V割 / V-cut**：拼板时，在板子边缘切出一个V型槽，方便以后掰开。
*   **邮票孔**：像邮票边缘一样的一排小孔，用于拼板连接，分板时容易掰断且边缘平整。
*   **老化 / 烤机**：把做好的数码管通电点亮很长一段时间。目的是把早期容易坏的次品提前淘汰掉。
*   **分板**：把一整块大板，掰成或切成一个个独立的数码管。
*   **炸胶**：灌进去的胶水因为温度太高或应力太大，内部开裂或者把塑料壳撑破。
*   **首件**：产线刚开始生产的前几个产品。必须拿给品质和技术确认没问题，才能大批量生产。

## 三、 品质与测试类（东西行不行）

*   **死灯 / 缺段**：数码管的某一笔不亮了，或者整个都不亮了。
*   **漏光 / 串光**：不该亮的地方（比如边缘缝隙）漏出了光，或者显示“1”的时候，“8”的其他笔画有微弱的光透出来（串光）。
*   **阴阳屏**：同一台设备上的几个数码管，有的偏黄，有的偏白，或者有的亮有的暗，看起来像阴阳脸。
*   **混BIN / 偏色**：工厂生产的芯片，颜色和亮度会有微小差异，出厂前会按参数分类（叫BIN）。如果装配时把不同颜色的混在一起用，就会被投诉偏色。
*   **虚焊**：看起来焊上了，但其实没连结实，稍微一碰或者用几天就断了。
*   **连锡 / 桥接**：两个挨得很近的引脚被一坨多余的锡连在一起了，导致短路。
*   **飞线**：电路板内部的线路断了，工人在外面人工用一根极细的线连起来补救（顶级不良，客户极度反感）。
*   **ESD / 静电**：冬天脱毛衣的噼啪声。能瞬间击穿芯片，让人查不出原因的“隐形杀手”。
*   **FA（失效分析）**：当产品坏得莫名其妙时，工程师用显微镜、打磨机把产品切开，查明到底是怎么死的。

## 四、 职场与流程类（平常怎么扯皮）

*   **封样**：产品做出来后，技术、品质和客户共同确认一个“标准实物”，贴上标签签上字，锁在柜子里。以后产线做出来的东西，必须和这个“标准件”一模一样。
*   **打样**：客户不下大订单，先做个几个或者几十个样品看看效果。
*   **开模**：为了生产特定形状的塑料壳子或板子，需要花重金去雕刻一套金属模具。
*   **打回 / NG**：不行、重做。
*   **特采**：这批货有一点小瑕疵，按理说不能收，但为了赶交期，客户或者领导特批“放行”了。
*   **ECN / 变更单**：产品要改设计、换材料、改尺寸时，必须在系统里走的一个审批单据。没这玩意儿就私自改，出了事要背锅。
*   **SOP / 作业指导书**：告诉产线工人具体怎么干活的说明书。第一步干什么，第二步干什么。
*   **踢皮球 / 闭环**：出了问题，销售说是技术的问题，技术说是工艺的问题，工艺说是采购的问题，这就是踢皮球。最后有人站出来把问题彻底解决并记录了，这就叫闭环。
