# 常见不良现象

在数码管（LED Seven-Segment Display）及显示模块的生产制造与客户端应用过程中，由于材料缺陷、工艺波动、设备精度或环境应力等因素，不可避免地会出现各种不良现象。

了解这些不良现象的表现形式、产生原因及排查方向，是研发工程师（PD）、工艺工程师（PE）和品质人员（QA）快速定位问题、闭环解决异常的基础。本文件对行业常见的物理与功能不良进行系统梳理。

## 一、 光学与显示类不良

### 1. 缺段 / 死灯（Dead Segment / Dead LED）
*   **表现**：数码管的某一个或几个笔画（段）无法点亮，或者完全不亮。
*   **可能原因**：
    *   **内部断线**：压焊环节金线/铜线断裂（如热应力拉扯、虚焊）。
    *   **芯片损坏**：受静电（ESD）击穿，或固晶银胶量不足导致接触不良。
    *   **外部虚焊**：引脚与客户PCB板焊接不良，或PCB内部过孔断铜。
    *   **驱动IC故障**：如果是带驱动芯片的模块，可能是IC对应引脚烧毁。
*   **排查**：用万用表二极管档测对应引脚，若不通，则为内部断线或芯片损坏。

### 2. 漏光 / 串光（Light Leakage）
*   **表现**：不该亮的地方（如塑壳缝隙、数字与数字之间、面膜边缘）透出光线。
*   **可能原因**：
    *   **塑壳缺陷**：塑壳壁厚太薄，或注塑时材料流动性问题导致局部缺料。
    *   **胶水问题**：灌胶未填满腔体（有气泡），或胶体与塑壳脱壳产生缝隙。
    *   **面膜偏位**：面膜贴偏或尺寸偏小，导致遮光区未完全覆盖。
    *   **内部隔断设计不合理**：多位数码管内部的隔光墙太矮或太薄。

### 3. 偏色 / 色差（Color Shift）
*   **表现**：发光颜色与客户确认的样品或规格书不符（如红偏橙、白偏蓝）。
*   **可能原因**：
    *   **芯片混料**：不同BIN级（波长）的芯片混用在同一块板子上。
    *   **荧光粉配比波动**：白光数码管（蓝转白）的荧光粉沉淀不均或比例失控。
    *   **电流波动**：驱动电流过大或过小导致波长漂移。

### 4. 亮度不均（阴阳屏 / Luminance Unevenness）
*   **表现**：同一面板上的多个数字，或者同一个数字的不同段，亮度差异明显。
*   **可能原因**：
    *   **物料混BIN**：不同亮度档位的灯芯混用。
    *   **限流电阻误差**：客户板端的限流电阻阻值偏差。
    *   **多路扫描占空比**：动态扫描时，个别位的驱动时间被压缩。
    *   **反射腔斜面差异**：塑壳反光碗的形状或光洁度不一致。

### 5. 重影 / 鬼影（Ghosting）
*   **表现**：动态扫描电路中，当前数字闪烁时，其他未选中的数字出现微弱漏光。
*   **可能原因**：
    *   **反向漏电流（IR）过大**：芯片质量缺陷。
    *   **软件消隐未做好**：位选切换时未及时关闭段选信号。
    *   **PCB表面漏电**：助焊剂残留或受潮导致微短路。

## 二、 外观与结构类不良

### 1. 塑壳变形 / 翘曲（Deformation / Warpage）
*   **表现**：底面不平，像“跷跷板”一样，或者长条形产品呈“弓”形。
*   **可能原因**：
    *   **注塑应力**：塑壳冷却不均，或脱模时拉伤。
    *   **过炉温度过高**：焊接时受热超出塑料的Tg点（玻璃化转变温度）导致软化变形。
    *   **板厚太薄**：PCB与塑壳刚性问题。

### 2. 炸胶 / 胶裂（Potting Crack）
*   **表现**：封装胶体表面出现裂纹，严重时胶体与塑壳分离（脱壳）。
*   **可能原因**：
    *   **冷热冲击过大**：胶水热膨胀系数（CTE）与塑壳不匹配，应力释放导致开裂。
    *   **固化工艺不当**：烘烤升温过快，胶水内部溶剂急剧挥发。
    *   **胶水配比错误**：A/B胶比例失调导致固化不完全，材质变脆。

### 3. 气泡 / 针孔（Bubbles / Pinholes）
*   **表现**：胶体内部或表面有肉眼可见的圆形空腔。
*   **可能原因**：灌胶前真空脱泡不彻底；注胶速度过快卷入了空气；塑壳内部有死角排气不畅。

### 4. 引脚歪斜 / 退针（Bent Pin / Push-out）
*   **表现**：引脚不直，或者引脚被外力顶入塑壳内部/拔出。
*   **可能原因**：包装挤压、运输碰撞；压PIN工艺中孔径公差过大，过盈量不足。

### 5. 毛刺 / 披锋（Burrs）
*   **表现**：注塑件边缘、引脚切断处、PCB分板处有明显的塑料或金属残留尖刺。
*   **可能原因**：模具磨损、冲切刀具钝化、注塑压力过大导致溢料。

## 三、 电学与可靠性类不良

### 1. 正向电压（VF）异常
*   **偏高**：内部接触电阻大（虚焊、银胶不足）。
*   **偏低（或短路）**：芯片内部结构损坏或受静电击穿。

### 2. 引脚生锈（氧化 / 盐雾失效）
*   **表现**：引脚表面发黑、发黄，或出现红锈，导致无法焊接。
*   **可能原因**：电镀层（镍层/锡层）太薄；存储环境湿度过高或含有腐蚀性气体；未通过盐雾测试。

### 3. 高温死灯 / 光衰严重
*   **表现**：常温测试正常，但在高温环境下（或使用一段时间后）亮度迅速下降甚至不亮。
*   **可能原因**：
    *   **散热不良**：PCB铜箔面积不够，或底部没有散热焊盘。
    *   **固晶胶失效**：高温导致银胶或绝缘胶老化脱层。
    *   **芯片外延缺陷**：抗衰减能力差。

## 四、 行业排查通用步骤

遇到不良时，建议采用“从外到内，从软到硬”的排查逻辑：
1.  **复现问题**：在测试治具或客户板端复现不良，确认是单点还是批次问题。
2.  **排除外部**：检查客户PCB焊接是否虚焊、驱动电路是否有问题（交叉验证法：换一颗好的数码管上去试）。
3.  **外观检查**：用高倍放大镜/显微镜观察引脚、塑壳、胶水是否有物理损伤。
4.  **破坏性分析（FA）**：剥开塑壳或打磨胶体，在显微镜下观察内部的打线、固晶是否存在断裂或空洞（需研发与品质介入）。
