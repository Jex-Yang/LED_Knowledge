# 光电参数指标

在数码管（LED Seven-Segment Display）及各类发光器件的制造、检验与选型中，光电参数是衡量产品性能的核心标准。光学参数决定了人眼看到的视觉效果，电学参数则决定了驱动电路的设计与产品的可靠性。

本文件对数码管行业通用的核心光学与电学参数进行系统梳理，以便在阅读规格书（DataSheet）或处理品质异常时参考。

## 一、 光学参数（Optical Characteristics）

光学参数描述的是数码管发光的表现形态，通常在标准测试电流（如 20mA 或 5mA）下测量。

### 1. 发光强度（Luminous Intensity，简称 IV）
*   **定义**：光源在特定方向上单位立体角内发出的光通量。通俗讲就是人眼感知的**“亮度”**。
*   **单位**：毫坎德拉（mcd）或坎德拉（cd）。
*   **行业特点**：不同颜色的发光强度差异极大。通常绿光、蓝光、白光的 IV 值较高，红光、黄光较低。在BOM表选型时，需注意同一面板上不同颜色数码管的亮度平衡，避免出现“阴阳屏”。

### 2. 主波长（Dominant Wavelength，简称 λD）
*   **定义**：人眼观察到的主色调所对应的单一波长。它决定了我们看到的是纯红、橙红还是正红。
*   **单位**：纳米（nm）。
*   **常见范围**：
    *   红光：620nm - 630nm（高于630偏橙，低于620偏粉）
    *   黄光：585nm - 595nm
    *   绿光：565nm - 575nm（黄绿）/ 515nm - 525nm（纯绿）
    *   蓝光：460nm - 470nm

### 3. 峰值波长（Peak Wavelength，简称 λP）
*   **定义**：发光光谱中能量最强（最高峰）的那个波长。
*   **区别**：由于LED发出的光并非单一波长，λP 是物理能量峰值，而 λD 是人眼视觉感知的主色。对于红光LED，两者数值接近；对于蓝光/白光LED，差异较大。一般工程应用看 λD 更多。

### 4. 色坐标（CIE x, y）
*   **定义**：在色度图上，用 x 和 y 两个坐标值来精确标定一种颜色。
*   **应用**：多用于白光（蓝转白）数码管或特殊颜色定制。客户对颜色要求极严时，通常会在规格书中规定坐标范围（如 X:0.29±0.02, Y:0.28±0.02），超出范围即为色偏不良。

### 5. 发光角度（Viewing Angle，简称 2θ1/2）
*   **定义**：发光强度降至最大值一半时所形成的夹角。
*   **应用**：常规数码管由于有反射腔聚光，发光角度通常在 120° - 140° 左右。角度越大，从侧面看越清晰；角度越小，正面越亮但侧面易出现暗区。

## 二、 电学参数（Electrical Characteristics）

电学参数决定了数码管如何与客户的电路匹配，以及功耗与安全性。

### 1. 正向电压（Forward Voltage，简称 VF）
*   **定义**：数码管在规定正向电流下，两端产生的电压降。也就是“点亮它需要多少伏的电压”。
*   **常见范围**：
    *   红、橙、黄光（AlGaInP材料）：通常为 1.8V - 2.2V。
    *   蓝、绿、白光（InGaN材料）：通常为 2.8V - 3.2V。
*   **工程意义**：VF 过高会导致发热增加，寿命缩短；VF 过低可能是芯片存在缺陷。客户端设计限流电阻时，必须参考 VF 的极值。

### 2. 正向电流（Forward Current，简称 IF）
*   **定义**：驱动数码管发光的额定电流。
*   **常见范围**：常规指示类数码管的工作电流通常为 10mA - 20mA。脉冲驱动（扫描）时，瞬时电流可更高。设计时应保证长期工作在推荐电流内，避免过驱导致光衰加速。

### 3. 反向漏电流（Reverse Leakage Current，简称 IR）
*   **定义**：给数码管施加规定的反向电压时，流过器件的微小电流。
*   **工程意义**：IR 越小，芯片质量越好。如果 IR 过大（漏电），在多路扫描电路中会导致“鬼影”（该灭的段微亮），或导致产品在高温高湿下功耗异常、加速老化。常规要求 IR ≤ 10μA。

### 4. 反向电压（Reverse Voltage，简称 VR）
*   **定义**：数码管所能承受的最大反向电压。
*   **工程意义**：LED 的反向耐压能力很弱，通常只有 5V 左右。若电路中存在反向浪涌，容易击穿芯片。在交流或可能接反的测试场景中，需外加防反接二极管。

### 5. 功耗（Power Dissipation，简称 Pd）
*   **定义**：数码管全亮时，所允许消耗的最大功率。
*   **工程意义**：超过此功率会导致芯片结温过高，胶体黄变，甚至烧毁。计算公式通常为：Pd = VF × IF × 点亮段数。

## 三、 参数异常与常见不良排查

1.  **亮度不足/光衰严重**：实测 IV 值低于下限。可能是芯片老化、封装胶水透光率下降，或长期超电流（IF过大）使用导致结温过高。
2.  **颜色偏色（比如整批偏黄或偏粉）**：实测 λD 或色坐标偏离规格范围。多为供应商混用了不同 BIN 级的芯片，或荧光粉配比在封装时出现波动。
3.  **微亮/鬼影**：IR 值超标，或电路板表面有离子污染导致漏电。
4.  **烧毁/死灯**：VF 实测短路或开路。可能是静电（ESD）击穿，或外部电路未加限流电阻直接接电源导致烧毁。
