# 七段显示原理

数码管（Seven-segment display）最基本的显示原理，是通过组合内部多个独立的发光段（Segment），来拼凑出阿拉伯数字、英文字母及其他符号。本文件详细说明七段数码管的构成、点亮逻辑及编码原理。

## 一、 基本构成：A~G 与 DP

标准的七段数码管由 8 个独立的发光二极管（LED）组成。之所以叫“七段”，是因为显示一个完整的数字“8”需要用到 7 根发光条（段），再加上右下角的一个小数点（DP，Decimal Point），实际上共有 8 个发光单元。

为了便于标识和控制，行业标准将这 8 个段进行了字母编号：
*   **A段**：最上面的一横
*   **B段**：右上角的一竖
*   **C段**：右下角的一竖
*   **D段**：最下面的一横
*   **E段**：左下角的一竖
*   **F段**：左上角的一竖
*   **G段**：中间的一横
*   **DP段**：右下角的小数点

```text
      A
     ---
  F |   | B
     -G-
  E |   | C
     ---  . DP
      D
```

## 二、 数字的组合逻辑

要显示某个数字或字符，只需点亮对应的发光段，熄灭其余的段。这种“点亮/熄灭”的组合即为显示逻辑。

以下是数字 0~9 的标准组合方式：

*   **0**：点亮 A、B、C、D、E、F（熄灭 G、DP）
*   **1**：点亮 B、C（熄灭 A、D、E、F、G、DP）
*   **2**：点亮 A、B、D、E、G（熄灭 C、F、DP）
*   **3**：点亮 A、B、C、D、G（熄灭 E、F、DP）
*   **4**：点亮 B、C、F、G（熄灭 A、D、E、DP）
*   **5**：点亮 A、C、D、F、G（熄灭 B、E、DP）
*   **6**：点亮 A、C、D、E、F、G（熄灭 B、DP）
*   **7**：点亮 A、B、C（熄灭 D、E、F、G、DP）
*   **8**：点亮所有 7 段（A、B、C、D、E、F、G）
*   **9**：点亮 A、B、C、D、F、G（熄灭 E、DP）

*除数字外，通过组合还可以显示十六进制的 A(AbCdEF)、字母 H、L、P 等，或用于显示特定的符号（如横杠、圆圈等）。*

## 三、 段码编码（Segment Code）

在单片机（MCU）或驱动芯片编程时，不可能逐个去控制每一根引脚的高低电平，而是会输出一个字节（8个位，Bit 0 ~ Bit 7）的数据，一次性控制 8 个段的亮灭。这个代表段状态的字节，称为**段码**。

段码的映射关系取决于硬件连线顺序。通常，数据位的最高位（MSB）到最低位（LSB）对应 `DP, G, F, E, D, C, B, A`。

由于存在**共阴**和**共阳**的区别，同一个数字的段码是**完全相反（按位取反）**的。

### 1. 共阴极（Common Cathode）段码表
逻辑为：**1 代表点亮，0 代表熄灭**。
（以二进制 `DP G F E D C B A` 顺序排列）

| 字符 | 二进制段码 | 十六进制 (Hex) |
| :--- | :--- | :--- |
| **0** | 0011 1111 | **0x3F** |
| **1** | 0000 0110 | **0x06** |
| **2** | 0101 1011 | **0x5B** |
| **3** | 0100 1111 | **0x4F** |
| **4** | 0110 0110 | **0x66** |
| **5** | 0110 1101 | **0x6D** |
| **6** | 0111 1101 | **0x7D** |
| **7** | 0000 0111 | **0x07** |
| **8** | 0111 1111 | **0x7F** |
| **9** | 0110 1111 | **0x6F** |

### 2. 共阳极（Common Anode）段码表
逻辑为：**0 代表点亮，1 代表熄灭**。（数据正好是共阴段码的按位取反）

| 字符 | 二进制段码 | 十六进制 (Hex) |
| :--- | :--- | :--- |
| **0** | 1100 0000 | **0xC0** |
| **1** | 1111 1001 | **0xF9** |
| **2** | 1010 0100 | **0xA4** |
| **3** | 1011 0000 | **0xB0** |
| **4** | 1001 1001 | **0x99** |
| **5** | 1001 0010 | **0x92** |
| **6** | 1000 0010 | **0x82** |
| **7** | 1111 1000 | **0xF8** |
| **8** | 1000 0000 | **0x80** |
| **9** | 1001 0000 | **0x90** |

*(注：不同软件工程师在定义PCB封装走线时，引脚与Bit位的对应关系可能不同，具体段码表需以实际硬件原理图和软件底层定义为准。)*

## 四、 多位数码管的动态扫描原理

在实际应用中（如显示“88:88”），为了节省引脚，多位数字并非同时被驱动，而是采用**动态扫描（多路复用）**技术。

1.  所有位的同名段（例如所有数字的A段）并联在一起，共用一个控制引脚（段选）。
2.  每一位数字的公共端（位选）独立引出，由另一组引脚控制。
3.  **扫描过程**：微控制器在极短的时间内（通常每次1~2毫秒），先输出第1位公共端有效，并输出第1位要显示数字的段码；接着关闭第1位，输出第2位公共端有效，并输出第2位的段码……以此类推。
4.  **视觉暂留**：因为扫描频率极高（通常大于60Hz），人眼无法察觉出闪烁，看起来就像是所有数字同时点亮一样。

## 五、 常见显示异常与故障排查

在设计或检验环节，可以通过缺失的笔画快速定位硬件故障：

*   **缺 A 段**：显示“8”时顶部不亮，显示“1”正常。
*   **缺 B 段**：显示“1”变成一横，显示“8”右上缺角。
*   **缺 G 段**：显示“8”变成“0”，显示“2”和“3”中间无横杠。
*   **多位显示重影**：动态扫描程序中“消隐”工作没做好，导致前一位的段码“漏”到了后一位。
*   **某些位特别暗**：动态扫描时，分配给该位的点亮时间（占空比）不足，或该位的公共端驱动电流不够。
